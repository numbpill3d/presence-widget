made for hand-built places

No account wall. No heavy client. The widget is a small script that renders wherever you put it: a Neocities sidebar, a README, a blog footer, a forum signature.

CLI first: presence set "your status". Clear it with presence clear. The status stays yours, and the fallback is readable plain text.
